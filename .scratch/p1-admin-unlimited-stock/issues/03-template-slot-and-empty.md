# 03: 样品槽语义与「还没设商品」

**What to build:** 管理员店的那个箱子明确变成"模板箱"：**第一个非空槽位就是样品槽**——买入不从它扣、卖出不往它放、交易前后逐字段相同；第一格以外的格子一律忽略；整个箱子空着时，这家店说「还没设商品」而不是「卖光了」。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 样品槽 = **第一个非空槽位**（每次现算，不是固定的 0 号槽）：0 号空、1 号放钻石时，钻石就是样品
- [ ] 交易前后样品槽逐字段不变（单测断言 `ItemStack` 相等；真机再点一遍）
- [ ] 第一格以外的格子**一律忽略**：不参与库存与空间计算，不构成拒绝理由（往第二格丢几组东西，买卖照旧）
- [ ] 模板箱空 → 新增一条不可交易原因：「这家管理员店还没设商品：往商店箱里放一件样品，它就卖这个」。它与普通店「商店箱里没有货」**用不同的判据与文案**，不许合并
- [ ] 点牌表单：模板箱空 → 不给买卖按钮；有样品 → 照常给。OP 的管理入口不受影响（能进去补样品）
- [ ] 换商品 = 换第一格的东西，不做任何持久化也不需要清空整箱；同一笔交易里商品只读一次
- [ ] 单测：样品槽判定（0 号空/1 号有）、其余格忽略、空箱原因与普通店原因分开、按钮集合在这两种状态下不同
- [ ] 真机：清空模板箱 → 点牌看到「还没设商品」且无按钮 → OP 放一件样品 → 立刻能买；第二格塞几组泥土 → 商品与份数都不受影响
- [ ] 文档：`DESIGN §7.4` 写清「模板箱不参与库存增减、卖进来的物品销毁（留档）」；`GLOSSARY.md` 加「样品槽」
