# 05: 卖一份与失败路径

**What to build:** 把交易反方向跑通：玩家把物品卖给商店，物品从背包消失、钱入账、库存增加。同时补齐所有拒绝路径：物品不匹配、店主资金不足、补偿失败时的冻结。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 卖成功：背包减少、余额增加、库存增加
- [ ] 玩家物品与容器商品不严格匹配（附魔、耐久、自定义名）→ 拒绝
- [ ] 店主余额不足 → 拒绝或按部分成交
- [ ] 店主离线且后端不支持离线 → 拒绝买与卖
- [ ] 构造一次"钱已动、物品搬失败"的场景，验证补偿把钱退回
- [ ] 补偿本身失败时：记严重日志、通知 OP、冻结该次操作，不自动重试
