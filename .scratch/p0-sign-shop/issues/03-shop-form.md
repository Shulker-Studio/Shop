# 03: 点牌看见商店

**What to build:** 点一块有效的商店牌，弹出表单显示店主名、商品名、每份件数、买价与卖价、当前可成交份数与玩家余额。余额在后端未就绪时显示占位。店主点自己的牌看到的是管理入口，没有买卖按钮。

同时验证一件必须实测的事：在交互阶段取消方块交互，是否真的不会弹出原版的告示牌编辑界面。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 点有效商店牌 → 弹信息表单，不弹原版编辑界面
- [ ] 表单里的店主、商品、份量、价格、库存与实际一致
- [ ] 店主点自己的牌 → 管理入口，无买卖按钮
- [ ] 点普通告示牌 → 照常弹原版编辑界面，不受影响
- [ ] 连续快速点牌 → 冷却期内只处理一次
- [ ] 记录实测结论：交互阶段取消是否阻止编辑界面弹出
