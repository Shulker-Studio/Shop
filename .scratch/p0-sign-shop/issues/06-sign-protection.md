# 06: 牌面防护

**What to build:** 非店主对商店牌的任何改动都无效：改文本、染料染色、墨囊、荧光墨囊、上蜡、除蜡。店主全部允许。上蜡之后连店主自己也要先除蜡才能改，但交易照常。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 非店主点牌不弹编辑界面（交互阶段就拦下）
- [ ] 非店主手持染料点牌 → 颜色不变
- [ ] 非店主手持墨囊或荧光墨囊 → 文字样式不变
- [ ] 非店主手持蜜蜡 → 牌子不上蜡
- [ ] 非店主手持斧头点已上蜡的牌 → 除不了蜡
- [ ] 店主执行以上全部操作 → 全部生效
- [ ] 上蜡后店主无法直接编辑，除蜡后可编辑
- [ ] 上蜡后的商店仍可正常买卖
