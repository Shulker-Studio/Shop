# 08: 破坏防护（方块级）

**What to build:** 爆炸、活塞、凋灵、火焰对商店箱无效，而旁边的一切照常。这是刻意偏离 Java 版的地方：不是取消整场爆炸，只是让商店箱从破坏目标里消失。

外加一条容易被忽略的路径：非店主拆掉商店牌依附的那块方块，会让牌子物理掉落、商店消失——等于绕过了"不能拆牌"。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] TNT 在商店箱旁爆炸 → 商店箱幸存，旁边方块正常被炸毁
- [ ] 活塞推商店箱 → 推不动；推旁边的方块 → 正常推动
- [ ] 活塞拉动商店箱 → 同样失败
- [ ] 凋灵破坏范围内含商店箱 → 商店箱不受影响，其他方块正常被破坏
- [ ] 火焰烧到商店箱 → 不燃烧
- [ ] 非店主拆掉商店牌背后那块墙 → 拆不掉，牌子不掉落
- [ ] 店主拆掉那块墙 → 可以拆，牌子随之掉落，商店消失（与拆牌等价）
- [ ] 以上事件对普通箱子照常生效
