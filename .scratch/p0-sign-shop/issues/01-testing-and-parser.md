# 01: 测试设施与解析器

**What to build:** 引入 doctest 与 `xmake test`；把告示牌正面的四行文本解析成商店定义（份量、价格对、是否管理员店），并把规范化后的四行拼回去作为字符串。

这一层不碰引擎：不 include 任何 `mc/*` 头，全部是纯字符串进、结构体出。它是后面每一步的回归保护，也是唯一能在没有 BDS 的情况下自动验证的东西。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] `xmake test` 能跑，至少一个测试用例通过
- [ ] 价格行：只写 `B`、只写 `S`、两者都写、`free`、带 `K`/`M` 后缀、带小数、零、负数、缺冒号、多余冒号，各自的解析结果正确
- [ ] 价格行：B 价低于 S 价时按配置拒绝
- [ ] 份量行：合法整数通过；0、负数、超过上限、非数字、带空格、Java 的 `Q 64 : C 64` 计数格式全部拒绝
- [ ] 份数计价：份价 × 份数、部分成交后的实际总价、1 份与上限份数的边界
- [ ] 管理员商店判定：配置名 + 是 OP → 管理员店；配置名 + 非 OP → 普通店
- [ ] 解析器与计价模块的源文件不含任何 `mc/` 头（用构建脚本或测试显式断言）
