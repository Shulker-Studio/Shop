# 02: 写牌子就开店

**What to build:** 在真实服务器里写完一块牌子，服务器把第 1 行换成编辑者当前的名字、第 4 行换成绑定容器里第一个非空槽位的物品名，然后把规范化后的四行写回牌子。写得不对时只提示原因并保留玩家的牌子。牌子成功连上容器后成为商店。

同时确立绑定规则：牌子必须**附着**在容器上——墙牌看背面、站立牌看下方、悬挂牌看悬挂点，只判断这一格是不是容器，不扫邻居。双箱合并成一个库存；一个容器同时只能被一块牌绑定。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 写合法四行 → 第 1 行与第 4 行被服务器覆盖成正确内容
- [ ] 第 3 行没有 `B` 或 `S` → 完全不处理，牌子原样保留
- [ ] 份量非法 → 收到提示，牌子保留原文本
- [ ] 容器为空 → 提示先放商品，不创建
- [ ] 墙牌贴在箱子侧面 → 成为商店；站立牌立在箱子顶面 → 成为商店
- [ ] 站立牌立在箱子旁边的地上 → 不是商店，提示"牌子要贴在或立在箱子上"
- [ ] 墙牌贴在箱子旁边的墙上 → 不是商店，同样提示
- [ ] 牌子没有附着容器 → 提示并保留
- [ ] 容器已被另一块牌绑定 → 拒绝，提示"这个箱子已经有商店了"
- [ ] 背面写商店格式 → 不生效
- [ ] 双箱：牌子只贴在一半上 → 可交易全部 54 格
- [ ] 双箱：两半各挂一块牌 → 第二块被拒（合并后是同一个库存）
