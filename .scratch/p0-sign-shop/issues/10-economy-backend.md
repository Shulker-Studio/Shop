# 10: 经济后端

**What to build:** 按 `auto` 顺序探测经济后端：LegacyMoney 优先，其次记分板，最后空实现。LegacyMoney 下每笔交易走一次原子转账；离线店主按后端能力决定能否交易；商店税与 LegacyMoney 的 `pay_tax` 冲突要显式警告。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 服务器装了 LegacyMoney → 自动使用它，交易能在其数据库中看到
- [ ] 没装 LegacyMoney → 回落到记分板，余额能正常增减
- [ ] 记分板目标名可配置，缺失时按配置决定是否创建
- [ ] 两家都没有 → 明确提示"没有可用经济后端"，交易按钮禁用
- [ ] 店主离线且后端不支持离线 → 买与卖都被拒绝并说明原因
- [ ] 店主离线且后端支持离线（LegacyMoney）→ 交易正常完成
- [ ] 商店税开启时：店主实收 `总额 - 税`，税被销毁；启动时打出要求关闭 `pay_tax` 的警告
- [ ] 余额写到 32 位后端时不会静默截断
