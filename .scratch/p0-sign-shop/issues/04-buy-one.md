# 04: 买一份

**What to build:** 选「购买」成交一份：钱扣掉、物品进背包、容器库存减少。这一条把记分板经济后端、交易服务、表单提交串成一条能看见的路径。失败路径（余额不足、库存不足、背包满）必须不留下任何半成品。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 成功购买后，余额、背包、库存三者数量一致
- [ ] 余额不足 → 提示，三者都不变
- [ ] 背包满 → 提示，三者都不变
- [ ] 库存不足且允许部分成交 → 按实际可成交份数成交，总价按份数重算
- [ ] 库存不足且不允许部分成交 → 整笔拒绝
- [ ] 表单里显示的总价与最终扣款一致，且为整数
- [ ] 交易失败时不留物品复制或金钱复制的窗口
