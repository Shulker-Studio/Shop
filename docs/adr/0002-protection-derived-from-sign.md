# 商店箱的保护状态从牌子推导，不写进容器

判断"这个箱子是不是商店箱、属于谁"，靠的是扫描与它相连的商店牌，而不是往容器里存任何标记。ChestLock 把 `Lock:/Perm:/Secret:` 字符串写进容器的 `CustomName`，效果是玩家打开箱子会在 GUI 标题里看到这一串原始文本；如果 Shop 也往同一个字段写，两个模组会互相覆盖。所以 Shop 完全不碰 `CustomName`，ChestLock 保持独立。

代价是每次保护判定都要扫一遍相邻方块并解析牌面文本。这个代价可以接受：判定只在交互、破坏、爆炸这些低频事件里发生，而且不需要清理"牌子已经没了但容器还记着归属"的残留状态。
